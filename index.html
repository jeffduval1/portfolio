01 · DonkeyNote : SaaS de gestion de missions (matrice Eisenhower)

🌐 https://donkeynote.app 🎬 Voir la capsule « La cote qui range »

Description du produit : SaaS complet de gestion de missions et de prise de notes conçu, développé et exploité de bout en bout. L'utilisateur attribue une cote de 1 à 10 à chaque mission, et la matrice Eisenhower la classe automatiquement dans le bon cadran, avec ajustement selon l'échéance.

Stack utilisé : React 18, TypeScript, Vite, TanStack Router et Query, CSS Modules, dnd-kit, Quill, PWA et service worker · Node.js, Fastify 5, Zod 4, Drizzle ORM, PostgreSQL sur Supabase (Montréal) · SDK Anthropic (Claude), SDK OpenAI (Whisper) · Clerk, Stripe, Microsoft Graph, AWS SES v2 et S3, Resend, Twilio, Web Push · Fly.io, Cloudflare Pages, Vitest, Playwright, Sentry

  • 🤖Classificateur IA : chaque note est classée dans la bonne catégorie par l'IA, avec file de revue et acceptation automatique au-delà de 0,92 de confiance.
  • 🎙️Dictée Whisper : transcription vocale dans les notes et les missions, vendue par forfait de 60 minutes à l'unité par Stripe.
  • 📅Synchronisation Outlook : OAuth Microsoft Graph, rendez-vous et séries sur le même jour civil des deux côtés, détection des doublons.
  • 🔔Rappels sans doublons : courriel (AWS SES), notification push et SMS avec réservation en base avant le départ entre deux serveurs.
  • 💳Abonnements et droits : Stripe à 5 paliers d'accès, webhooks signés et droits vérifiés côté serveur.
  • 📴PWA hors ligne et bilingue FR/EN : quatre filets contre l'écran blanc après mise à jour, corbeille et import/export en 3 stratégies avec copie de sécurité.
  • 🧪Tests et résilience : près de 2 000 tests unitaires et serveur (Vitest) et environ 300 tests E2E Playwright (iPhone SE 320 px, iPhone SE, iPhone 14) sur base Postgres jetable ; sauvegardes en 3 couches testées sur 93 tables.

02 · Propulsion Numérique : mon agence web et ses moteurs logiciels

🌐 https://propulsion-numerique.ca 🧭 Boussole entrepreneuriale

Description du projet : Mon agence web québécoise. Au-delà d'un thème WordPress sur mesure, j'y ai bâti un écosystème de moteurs logiciels autonomes conçus dès le départ pour être installés et vendus séparément chez des clients tiers.

Stack utilisé : WordPress sur mesure, ACF Pro, PHP, SCSS, JavaScript modulaire · Moteur social : React 18, TypeScript, Vite · Modèles et API d'IA : Anthropic Claude (Sonnet 4.6, Haiku 4.5), OpenAI · WP Engine (prod et staging), GitHub Actions, Postmark (webhooks), GA4, Meta Pixel, Consent Mode v2

  • 🧭Boussole entrepreneuriale (en ligne) : questionnaire de qualification de 33 questions qui bifurque selon qu'on a un site ou non, lecture personnalisée générée par l'IA (prompt v1.41 versionné et gelé) et suivi d'abandon question par question dans GA4.
  • ✍️Moteur éditorial 2.0 (en préparation · sortie prochaine) : l'outil qui écrit les articles d'une entreprise dans sa propre voix ; plus de 200 décisions de conception consignées avant d'écrire le code et voix décortiquée sur bancs d'essai.
  • 📲Moteur social : extension WordPress avec façade en React 18, TypeScript et Vite (calendrier de publications, récurrences à paliers progressifs, suivi des publicités, multi-entreprises, installation par simple .zip).
  • 🛡️Moteur de soumissions et surcouche courriel : pipeline de 9 étapes (normalisation, assainissement, validation, jeton JS, piège à robots, limite de débit, idempotence, enregistrement, envoi Postmark avec journal et webhooks).
  • 📊Portail statistiques : 7 sources interrogées par API (base de données du site, Postmark, GA4, Search Console, Meta, Google Business Profile, WP Engine), historique CSV cumulatif avec rattrapage de 30 jours et bilan écrit envoyé par courriel tous les 3 jours.

03 · Certi-Pro : site sur mesure et outils IA d'un garage automobile

🌐 https://certi-pro.ca 🎬 Voir les capsules RDV et Rappel d'entretien

Description du projet : Site sur mesure d'un garage automobile de Charlesbourg (client réel), en production depuis août 2026 et sous contrat d'entretien mensuel.

Stack utilisé : WordPress sur mesure, ACF Pro, PHP, SCSS, JavaScript modulaire · Fichiers JSON à écriture atomique · Modèles et API d'IA : Anthropic Claude (Sonnet 4.6, Haiku 4.5), OpenAI GPT-4o-mini · WP Engine, Cloudflare, GitHub Actions, Postmark, API Pexels, GA4, Consent Mode v2

  • 🔧Moteur de calendrier d'entretien par IA (actif) : le client entre son véhicule ; Claude Sonnet cherche en ligne le calendrier réel du constructeur, le code calcule la priorité (jamais l'IA), et Claude Haiku rédige avec sources et niveau de confiance obligatoires. Coût d'usage suivi en dollars.
  • 📋7 formulaires métier : rendez-vous, forfaits, compagnie, policiers et militaires, PromoLoco, carrière (envoi de CV), plainte. Étapes multiples, validation conditionnelle (NIV obligatoire selon le service) et liens profonds préremplis.
  • 🔍Protocole d'entretien par IA : entretien mensuel en 6 phases et 52 points de contrôle avec collecte automatique, preuves obligatoires et contre-vérification par un second agent.
  • 📰Moteur de blog assisté par IA : 6 patrons de contenu, accroches générées par l'IA, suggestions de maillage interne, 3 mises en page et 8 commandes en ligne de commande pour le traitement par lots.

À propos

Je suis Jean-François Duval, développeur full stack TypeScript et fondateur de Propulsion Numérique et de DonkeyNote à Québec.

En parallèle de mon poste au gouvernement du Québec (MELCCFP, après le MAMH), j'ai bâti et mis en production plusieurs produits complets : le SaaS DonkeyNote (https://donkeynote.app), le site et les moteurs logiciels de mon agence Propulsion Numérique (https://propulsion-numerique.ca) ainsi que la plateforme et le calendrier d'entretien par IA du garage Certi-Pro (https://certi-pro.ca).

Je travaille quotidiennement avec plusieurs agents de programmation en parallèle (Claude Code, Cursor, Codex, Gemini), encadrés par 33 protocoles écrits, des revues croisées systématiques et des suites de tests automatisés rigoureuses. Pour moi, l'IA qualifie et rédige là où elle excelle, mais le code garde toujours le dernier mot sur la logique critique, la sécurité et les données.
